# Hard-source audit

Audit date: 2026-09-10.

- The 2024-2026 text-only corpus has 26 questions, 0 answer keys, and 0 worked solutions.
- Its `analysis.problem_graph` fields were generated by a model and are not authoritative solutions.
- Retrieval bundles label graph neighbors as `solution_exemplars`, but those records contain only
  `question_text`, `graph_text`, topic, and an inferred difficulty.
- The 2024 Q23 graph used an incorrect signed relative velocity; a generator copied that error.
- The older `ablation_3/plain_solutions.jsonl` has 380 synthesized solutions from 2008-2020. They do
  not cover 2024-2026 and have no stored official-answer provenance or verification status.
- `ablation_3/solution_embedded.jsonl` has 380 embeddings but an empty `solution_text` field in every
  row. `solution_embedded_k6_6_6_longctx.jsonl` retains the text, but correctness is still unverified.

Conclusion: the repository has useful questions, embeddings, and inferred structures, but it does not
yet have a verified recent hard-solution corpus. That missing corpus must be built before D4 retrieval
or generation can be trusted.
