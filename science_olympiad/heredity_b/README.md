# Heredity B graph-first RAG banks

This directory contains preserved pilot/checkpoint banks plus a production 10-item Science Olympiad Division B Heredity bank generated and audited with exact model `gpt-5-mini`. It is grounded in public practice materials linked from the official Heredity page. It does **not** download, parse, quote, embed, or otherwise use the official rules manual.

## Outcome

The release bank is `gpt5mini_run/generated/items_model_final.jsonl`:

- All 10 questions and all 10 graph-first plans were generated by `gpt-5-mini`.
- All 10 questions passed independent answer-hidden judging by `gpt-5-mini`.
- The final holistic bank audit was performed by `gpt-5-mini` and passed.
- Dual prompt/structure retrieval uses real 1,536-dimensional `text-embedding-3-small` vectors over 62 valid paired source anchors.
- All seven configured topic families are covered. Deterministic, recomputation, embedding-novelty, and holistic audits pass.
- Per-call usage, a usage summary, retrieval provenance, one capped failed trial, and resumable checkpoints are retained under `gpt5mini_run/`.

Earlier artifacts remain intact: `run/` contains the 10-item agent-authored provisional pilot, while `model_run/` retains the three-item `gpt-5.1` checkpoint. Neither is part of the `gpt-5-mini` release bank.

## Preserved provisional pilot

- 63 paired, text-safe source anchors: 50 BullSO 2026, 8 Berkeley 2026, and 5 official-hosted UT-Austin sample items.
- 10 original pilot items: 5 MCQ, 3 short answer, and 2 numeric.
- Seven topic families represented: Mendelian probability, non-Mendelian inheritance, sex-linked inheritance, cell division/chromosomes, DNA structure/replication, gene expression, and mutations/biotechnology.
- Every item begins with a reasoning graph and uses a retrieval bundle combining prompt-space (55%) and graph-space (45%) similarity.
- All 10 pass schema checks, answer-hidden deterministic recomputation, duplicate checks, and local source-novelty thresholds.
- External blind model judging was not performed because neither an OpenAI credential nor Ollama was available. This is recorded explicitly in the reports and checkpoint; no internal review is mislabeled as external or blind.

The current official page says 2027 resources are “coming soon.” Consequently, the downloaded 2026 invitationals and official older samples calibrate observed breadth and style but are not represented as current rules. See `source_manifest.json` for URLs, hashes, counts, exclusions, and the unresolved Pembroke folder.

## Reproduce the provisional pilot

```bash
python3 -m src.heredity.pipeline
python3 -m src.heredity.audit
python3 -m pytest -q tests/test_heredity_pipeline.py
```

The default run is deterministic and makes no model calls. It rebuilds the corpus, two 384-dimensional feature-hash indexes, retrieval bundles, plans, and items. To realize the audited plans through a model after configuring `OPENAI_API_KEY`:

```bash
OPENAI_USAGE_LOG=science_olympiad/heredity_b/run/openai_usage.jsonl \
python3 -m src.heredity.pipeline --mode model --model gpt-5-mini
```

Model output is written separately to `generated/items_model.jsonl`; it does not overwrite the validated pilot. It must receive a new blind solve/judge pass before release.
